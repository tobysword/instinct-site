Download

Install Instinct.

Windows 10 or 11 (64-bit). No administrator rights needed. Downloads come from our GitHub releases.

Downloads

Instinct-Setup.exe Recommended

Per-user installer. Installs to %LOCALAPPDATA%\Instinct, adds a Start menu entry and lives in the system tray.

Download Instinct-Setup.exe

Instinct-portable.zip

No install: unzip it anywhere and run Instinct.exe.

Download portable zip
Windows SmartScreen. The build isn't code-signed, so Windows may show "Windows protected your PC". Click More info, then Run anyway.

Verify your download

Every release has a SHA256SUMS.txt. In PowerShell, compare the hash of your file with the line for it:

Get-FileHash .\Instinct-Setup.exe -Algorithm SHA256
Set up

Three steps, then play.

  1. Download

    Get Instinct-Setup.exe above.

  2. Run

    No admin rights. If SmartScreen appears: More info → Run anyway.

  3. Setup check

    Turns on the Stats API in one click (backup first). Restart Rocket League.

Play in Borderless or Windowed mode. In exclusive Fullscreen, Windows can't draw anything over the game.
Prefer to do it yourself?

Turn on the Stats API by hand

  1. Quit Rocket League.
  2. Open Documents\My Games\Rocket League\TAGame\Config\ and edit DefaultStatsAPI.ini in Notepad.
  3. Under [TAGame.MatchStatsExporter_TA] set:
[TAGame.MatchStatsExporter_TA]
PacketSendRate=30
Port=49123
  1. Save and start Rocket League again (it reads this file only at startup).

PacketSendRate is updates per second; 0 (the default) means off.

Upgrading

From RL Coach Companion

The installer removes the old program and keeps your data in %APPDATA%\rl-companion. Your history, players and settings carry over.

Updates

Signed, in the app

Updates are signed and offered in the app. Stable channel only.

Uninstall

Any time

Settings → Apps → Installed apps → Instinct → Uninstall. Your data stays in %APPDATA%\rl-companion until you delete it.
