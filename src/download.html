Install

  1. Run the installer

    No administrator rights needed: it installs for your Windows user only. It lives in the system tray once it starts.

    "Windows protected your PC"? The installer isn't code-signed yet, so Windows SmartScreen shows this for new apps. Click More info, then Run anyway. To check the file first, compare its SHA-256 with SHA256SUMS.txt (below).

  2. Run the setup check

    {{PRODUCT_NAME}} finds your Rocket League install and turns on the Stats API in one click, backing up the original file first. Then restart Rocket League (it reads the setting only at startup).

  3. Use Borderless or Windowed

    In Rocket League's video settings, pick Borderless or Windowed. In exclusive Fullscreen, Windows can't draw anything on top of the game.

  4. Play a match

    About 75 seconds in, the overlay shows what you're playing like. Ctrl+Shift+O shows or hides it. Between games, open {{PRODUCT_NAME}} from the tray.

What you need

Uninstall

Windows Settings → Apps → Installed apps → {{PRODUCT_NAME}} → Uninstall. Your data stays in %APPDATA%\rl-companion until you delete it.

Turn on the Stats API by hand

The setup check does this for you. If you'd rather do it yourself:

  1. Quit Rocket League.
  2. Open Documents\My Games\Rocket League\TAGame\Config\ and edit DefaultStatsAPI.ini in Notepad.
  3. Set these lines, then save and start Rocket League again:
[TAGame.MatchStatsExporter_TA]
PacketSendRate=30
Port=49123

PacketSendRate is updates per second; 0 (the default) means off. The Stats API only sends data to programs on your own PC.

Check the download

In PowerShell, in your Downloads folder, run this and compare the result with the line for the same file in SHA256SUMS.txt:

Get-FileHash .\Instinct-Setup.exe -Algorithm SHA256
