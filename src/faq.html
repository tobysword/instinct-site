Can I get banned for using {{PRODUCT_NAME}}?

{{PRODUCT_NAME}} only uses Rocket League's official local Stats API, optional capture of the game window and replay files you saved. It never reads game memory, injects code or hooks the game. It never presses keys, and nothing goes to chat. We can't speak for Psyonix or Epic, so please follow their terms and any tournament rules.

Is it free?

The core is. The live overlay, post-match Reads, local match history and sign-in are free. {{PRO_NAME}} ($2.99/month) adds Toxic mode, cloud sync, team sharing, cloud export, session tracking, local growth tracking and the phone companion. See Pricing.

Does it coach rotation?

Not live. The Stats API doesn't send positions, so the live overlay shows facts it can see. Replay analysis (experimental) adds positions from replays you saved. More in What it can't see.

What platforms are supported?

Windows 10 and 11, for Rocket League on Steam or Epic Games. The phone companion ({{PRO_NAME}}) works in your phone's browser on the same Wi-Fi.

Why can't I see the overlay?

Play in Borderless or Windowed mode. In exclusive Fullscreen, Windows can't draw anything on top of the game. Then run the Setup check in the app to make sure the Stats API is on.

Does it slow down my game?

The app is a lightweight native Windows app built with Tauri. It reads data the game already publishes locally, so the impact is minimal.

Do I need an account?

Not to play. The live overlay, post-match Reads and local match history work without one. Sign-in is free and lets you buy or redeem {{PRO_NAME}}.

Can I stream with it?

Yes. Turn on Hide player names in Settings and lobby rows and post-match show Teammate n / Opponent n. If you use Toxic mode on stream, you're responsible for what your overlay shows; {{PRODUCT_NAME}} warns you once.

What data do you collect?

Game data stays on your PC; the Stats API is local-only. Phone traffic stays on your Wi-Fi. No ads, no analytics, no data selling. Data leaves your PC only if you choose: an account and cloud sync, opt-in crash reports (off by default; asked once) or feedback you send. Update checks go to GitHub. Read the Privacy Policy.
