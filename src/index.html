How it works

Built on Rocket League's official Stats API.

Psyonix ships a local Stats API with the game. {{PRODUCT_NAME}} reads it, nothing more.

  1. Install

    Download the Windows installer from GitHub Releases and launch {{PRODUCT_NAME}}.

  2. Enable the Stats API

    One click turns it on in Rocket League's DefaultStatsAPI.ini. A backup is made first.

  3. Play

    Live match data streams to the app on your PC and the overlay starts coaching.

  4. Improve

    Review post-match summaries, your rank drivers and trends over time.

Anti-cheat friendly

{{PRODUCT_NAME}} is a coaching tool, not a cheat or automation tool.

  • No reading of game memory, no code injection, no hooks into the game process.
  • No automated key presses or inputs.
  • Does not use or require BakkesMod.

FAQ

Questions, answered.

Can I get banned for using {{PRODUCT_NAME}}?

{{PRODUCT_NAME}} only uses Rocket League's official local Stats API, optional capture of the game window and replay files you saved. It never reads game memory, injects code, hooks the game or presses keys for you. We can't speak for Psyonix or Epic, so please follow their terms and any tournament rules.

Is it really free?

Yes. The core coach is free. {{PRO_NAME}} is free for everyone during the beta; after the beta it costs US $2.99/month, and we give at least 30 days' notice before any charge.

What platforms are supported?

Windows 10 and 11, for Rocket League on Steam or Epic Games. The optional phone companion works in your phone's browser on the same Wi-Fi.

Does it slow down my game?

The app is a lightweight native Windows app built with Tauri. It reads data the game already publishes locally, so the impact is minimal.

Do I need an account?

No. Coaching works fully offline on your PC. An account is only needed for {{PRO_NAME}} cloud features like sync across PCs and teams.

What data do you collect?

None by default. Match data stays on your PC. Data only leaves it if you create an account, opt in to crash reports or send feedback. No ads, no analytics, no selling data. Read the Privacy Policy.

How do refunds work?

Once paid plans launch, you can request a full refund within 14 days of your first payment, and cancel any time. See the Terms.

Is {{PRODUCT_NAME}} affiliated with Psyonix or Epic Games?
